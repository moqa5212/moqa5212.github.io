Mac 最佳中文输入方案（一）：使用 Fcitx5 中州韵版搭建 Rime 输入环境

发表于2026-07-09|更新于2026-07-09|ApplemacOS
|总字数:1.3k|阅读时长:4分钟|浏览量:

对于每天需要编写代码、撰写文档或者维护博客的人来说，输入法早已不仅仅是一个文字输入工具，它更是整个工作流中使用频率最高的软件之一。选择一套稳定、高效且可定制的输入方案，往往比更换键盘或者升级硬件带来的提升更加明显。

这些年，我陆续尝试过 macOS 原生输入法、搜狗输入法以及鼠须管（Squirrel）等不同方案。虽然它们都能够满足基本的中文输入需求，但随着 Markdown 写作、终端开发以及中英文混输场景越来越多，我开始希望拥有一套真正能够按照自己习惯进行定制的输入法。

最终，我选择了 Fcitx5 + Rime + 雾凇拼音（rime-ice） 这一组合。

本文将作为整个系列的第一篇，按照 Fcitx5 macOS 官方推荐的安装方式，带你完成输入法环境的搭建。我们将使用官方提供的 Fcitx5 中州韵版（Rime Edition），整个过程无需编译源码，也无需额外安装 Rime 插件，安装完成后即可直接导入雾凇拼音开始使用。

为什么选择 Fcitx5？

很多刚接触 Rime 的用户，都会在鼠须管（Squirrel）和 Fcitx5 之间犹豫。

实际上，两者都可以运行 Rime，只是设计思路有所不同。

Fcitx5 并不是单独的中文输入法，而是一套现代化的输入法框架，它负责管理输入法状态、候选窗口、快捷键以及插件系统，而真正负责中文输入的则是 Rime 引擎。

整个架构可以简单理解为：

相比传统输入法，Fcitx5 最大的优势在于模块化设计，它将输入法框架和输入方案完全分离，因此后续更换输入方案、同步配置或者安装扩展都会更加方便。

安装前准备

本文适用于以下环境：

项目 版本
macOS Sequoia 15 或更新版本
芯片 Apple Silicon / Intel
Fcitx5 官方最新版（中州韵版）

第一步：下载 Fcitx5 中州韵版

目前，Fcitx5 macOS 官方提供了多个安装版本。

如果你的目标是使用 Rime，建议直接下载 中州韵版（Rime Edition）。

该版本已经内置：

  • Rime 输入引擎
  • librime 运行环境
  • 中州韵相关组件

GitHub 安装

打开 Fcitx5 官方下载页面，选择最新版 中州韵版。

安装包本身适用于 Intel 和 Apple Silicon，但会根据您的机器类型，安装单一架构的输入法，减少不必要的空间占用。

一键安装

第二步：授予系统权限

当您解压并打开安装程序时，系统可能阻止您打开未认证的程序。这是因为苹果软件认证需要开发者付出订阅费用，免费软件开发者难以接受订阅成本而没有进行认证，不影响软件正常使用。

为了保证输入法能够正常工作，可以手动进入：

系统设置 → 隐私与安全

确认 仍要打开 Fcitx5Installer。

完成授权后，重新打开安装程序即可。

第三步：添加 Fcitx5 输入法

接下来打开：

系统设置 → 键盘 → 输入法

点击 编辑。

选择：

在列表中找到：

点击添加。

添加完成之后，建议保留：

  • ABC
  • Fcitx5

这样切换输入法更加简洁，也避免多个中文输入法共存带来的冲突。

如果之前安装了搜狗、百度或者系统拼音，可以等迁移完成之后再删除。

第四步：导入雾凇拼音

雾凇拼音（rime-ice）是目前 Rime 社区维护最活跃、体验也最成熟的一套配置方案。

相比默认配置，它拥有更加合理的候选排序、更完善的词库以及更符合现代中文输入习惯的默认设置，因此也是目前最推荐的新手方案。

首先打开 Rime 用户目录（~/.local/share/fcitx5/rime ），也可通过点击屏幕菜单栏中小企鹅输入法图标->输入法，在输入法页面中通过用户数据目录进入。

随后，将下载好的 雾凇拼音 配置文件复制到该目录。

第五步：重新部署

复制配置文件之后，还需要执行一次 Deploy（重新部署）。

点击菜单栏中的 小企鹅输入法，选择：

等待部署完成。

第一次部署通常需要几十秒，因为需要生成词典索引。

部署完成之后，重新切换输入法即可开始使用。

小结

本文按照 Fcitx5 官方推荐方式，完成了整个输入环境的基础搭建，包括：

  • 下载并安装 Fcitx5 中州韵版；
  • 配置 macOS 所需权限；
  • 将 Fcitx5 添加到系统输入法；
  • 启用内置 Rime 输入引擎；
  • 导入雾凇拼音配置；
  • 完成首次部署。
