Hexo 个人网站搭建教程

一、Hexo简介

Hexo 是一个快速、简洁且高效的静态博客框架，基于 Node.js 开发。通过 Markdown 编写文章，Hexo 可以快速生成静态网页，并部署到 GitHub Pages、Vercel、Netlify 等平台。

Hexo特点

  • 简单易用
  • 支持 Markdown
  • 丰富的主题生态
  • 快速生成静态页面
  • 免费部署
